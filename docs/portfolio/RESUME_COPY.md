# 履歷與社群平台文案

## 中文履歷｜建議版

### 擁抱內在批評者｜全端個人作品

一個低干擾的引導式自我覺察日記，幫助使用者逐步辨認觸發情境、內在批評、情緒與行為之間的關係。

- 將自我覺察需求拆解為一次一題的六步驟互動流程，使用 Nuxt 4、Vue 3 與 TypeScript 完成前端體驗。
- 使用 ASP.NET Core 10、EF Core 與 PostgreSQL 建立 Google 登入及使用者專屬日記 CRUD。
- 實作資源所有權查詢、Cookie 寫入的 CSRF 防護、rate limit、request size、分頁及每帳號日記額度限制。
- 針對敏感情境提供跳過、停止與主動求助入口，並刻意不以 AI 代寫、改寫或補完使用者的覺察文字。

**Tech Stack：** Nuxt 4、Vue 3、TypeScript、Tailwind CSS 4、ASP.NET Core 10、EF Core 10、PostgreSQL、Supabase、Google OAuth

## English resume

### Embrace Your Inner Critic | Full-stack Personal Project

A low-distraction guided reflection journal that helps users separate triggering situations, self-critical thoughts, emotions, and behavioral responses through a one-question-at-a-time experience.

- Translated a sensitive reflection process into a six-step guided flow using Nuxt 4, Vue 3, and TypeScript.
- Built Google authentication and user-scoped journal CRUD with ASP.NET Core 10, Entity Framework Core, and PostgreSQL.
- Added resource ownership checks, CSRF protection for cookie-authenticated writes, rate limiting, request-size limits, pagination, and a per-account journal quota.
- Designed opt-out, pause, and help-seeking paths while deliberately avoiding AI-generated or rewritten reflection content.

**Tech Stack:** Nuxt 4, Vue 3, TypeScript, Tailwind CSS 4, ASP.NET Core 10, Entity Framework Core 10, PostgreSQL, Supabase, Google OAuth

我把一段很難開始的自我覺察過程，做成一次只需要回答一個問題的互動式日記。

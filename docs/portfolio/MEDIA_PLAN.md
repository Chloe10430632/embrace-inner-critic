# 作品集圖片與 GIF 製作清單

## 共用假資料

所有畫面使用同一組低敏感度的虛構內容：

- 內在批評者名稱：`小刺`
- 觸發情境：`在會議中被問到還沒完成的工作。`
- 批評句：`你是不是又準備不夠？`
- 情緒：`焦慮`、`羞恥`
- 行為：`過度工作`、`反覆確認`
- 較早經驗：`讓我想到以前回答錯問題時，很怕被責備。`
- 回應：`我可以先確認最重要的一步，不需要一次做到完美。`

不要使用真實個案、諮商內容、email、Google 帳號或私人日記。

## 核心流程 GIF 分鏡

總長控制在 12–18 秒，只呈現能讓觀看者理解互動的片段。

| 時間 | 畫面 | 操作重點 |
| --- | --- | --- |
| 0–3 秒 | 內在批評者從旁探頭 | 保留角色動畫，不快速晃動滑鼠 |
| 3–6 秒 | 輸入名稱「小刺」 | 游標移動一次即可 |
| 6–10 秒 | 進入日記問題 | 輸入一行簡短假資料 |
| 10–13 秒 | 選擇焦慮、羞恥標籤 | 讓選取狀態清楚可見 |
| 13–18 秒 | 回顧並點亮地圖節點 | 停留 1–2 秒再循環 |

### 錄製設定

- 首選 viewport：`1440 × 900`。
- 最終輸出寬度：`960–1100px`。
- GIF／WebP：12–15 fps 即可，不需要 30 fps。
- 滑鼠移動要少、慢且有目的；關閉通知與密碼管理器提示。
- 背景音樂不需收錄在 GIF；若製作影片版，再另外保留聲音。
- 建議同時輸出無聲 WebM 或 MP4，避免 GIF 檔案過大。
- 若登入流程會顯示帳號資訊，從已登入且資料已匿名化的畫面開始錄。

## 截圖構圖原則

- 首圖優先呈現產品價值，不要把大量導覽列或瀏覽器空白留在畫面中。
- 每張圖只證明一件事，搭配一句「設計目的」，不要只寫畫面名稱。
- 桌面與手機畫面不要硬塞在同一張小圖；作品集頁分開排列。
- 保留目前白、黑、亮綠的品牌辨識，不另加與產品無關的漸層背景。
- 不要用插畫取代真實產品截圖；插畫應出現在實際介面脈絡中。

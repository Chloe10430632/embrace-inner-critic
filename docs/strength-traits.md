# 特質與能力標籤：分類研究與產品選擇

研究與整理日期：2026-10-12。預設詞彙見 `frontend/app/data/strengthTraits.ts`。

## 建議採用的方向

使用「特質與能力」作為總稱。人格傾向、品格、可練習的技能與日常照顧行動並非同一種概念，但都可以成為事件中被看見的力量。分類用來找標籤，不用來評定人格或能力高低。

以下九類是針對本產品整理的分類，並非任何一套量表的官方版本。先提供 70 個預設標籤，不設標籤種類總額上限，使用者可持續自訂；每筆事件仍最多選 10 個。每類有 7–9 個起始選項，是為了讓瀏覽負擔相近，不代表各能力在心理測量上等量、獨立或同等重要。

## 參考框架與取捨

- [VIA：24 項人格優勢](https://www.viacharacter.org/character-strengths)涵蓋好奇、勇氣、善意、公平、審慎、感恩、幽默等。適合提供品格與優勢詞彙，但不能單獨涵蓋寫作、工具操作與生活技能。
- [OECD：社會與情緒能力](https://www.oecd.org/content/dam/oecd/en/publications/reports/2023/11/social-and-emotional-skills_9a01e852/ba34f086-en.pdf)以任務表現、情緒調節、與人互動、合作與開放心態等面向組織能力。這裡借用其覆蓋面，不移用學生評量分數，也不把外向、始終樂觀或抗壓當成每個人都應達成的標準。
- [O*NET：能力、技能與工作風格](https://www.onetcenter.org/content.html)區分能力、習得技能和工作風格，並包含認知、身體與實作面向。可補足解題與實作，但本產品不直接使用職業適配或求職評分。
- 「自我照顧與界線」是依本產品用途另外整理的分類：讓休息、求助和表達需要也有位置，而不是只承認產出與堅持。這是產品設計選擇，不宣稱是上述框架原有的獨立因素。

## 九個分類

| 分類 | 標籤 | 可以記錄的事件例子 |
| --- | --- | --- |
| 探索與學習 | 好奇心、學習力、觀察力、專注力、開放心態、反思能力、知識整合 | 為不懂的事情提問；從回饋調整做法；把新知和既有經驗連起來。 |
| 思考與解題 | 分析能力、邏輯推理、判斷力、批判思考、全局觀、問題解決、決策能力、數量推理 | 拆解困難；查證資訊；比較選項後作出決定。 |
| 創意與表達 | 創造力、想像力、美感、寫作能力、表達能力、說故事能力、幽默感、藝術表現 | 寫清楚一段文字；做出作品；用適當的幽默讓氣氛放鬆。 |
| 行動與執行 | 勇氣、主動性、毅力、自制力、責任感、整理能力、規劃能力、時間管理、細膩 | 害怕時仍嘗試；安排步驟；準時赴約；注意被忽略的細節。 |
| 人際與合作 | 同理心、傾聽能力、友善、尊重他人、合作能力、協調能力、領導能力、教導能力 | 聽懂對方需要；協調分工；把自己的方法教給別人。 |
| 品格與價值 | 誠實、守信、公平、謙遜、感恩、審慎、希望感、意義感 | 承認錯誤；做到承諾；公平分配機會；做出符合價值的選擇。 |
| 情緒與調適 | 自我覺察、情緒辨識、情緒調節、耐心、適應力、挫折調適、壓力調適 | 注意自己的反應；說出感受；受挫後調整節奏。 |
| 自我照顧與界線 | 自我照顧、自我接納、適時休息、界線表達、主動求助、需求表達、健康習慣 | 很累時休息；拒絕超出負荷的要求；尋求協助；照顧日常需要。 |
| 生活與實作 | 數位工具運用、技術實作、手作能力、空間感、身體協調、運動技能、生活料理、財務管理 | 使用工具解決問題；修理或製作東西；完成一道料理；安排收支。 |

## 容易混淆的詞彙

- 觀察力：注意資訊；細膩：注意細節與品質；同理心：理解他人的感受。它們可能共同出現在一件事中，但不是同義詞。
- 分析能力：把資訊拆開理解；邏輯推理：檢查推論關係；判斷力：衡量證據；決策能力：在情境與限制中作出選擇。
- 勇氣：有害怕或不確定時仍行動；主動性：自己開始；毅力：持續嘗試；自制力：調整衝動或行動以符合當下目標。
- 守信：履行承諾；責任感：承擔份內事與後果；時間管理：安排時間。準時可能對應三者，依事件選擇，不必全部套上。
- 自我覺察：注意自己的想法、感受與反應；情緒辨識：辨認與命名感受；情緒調節：用可行方法回應感受，而非壓抑或消除情緒。
- 界線表達：說清楚能接受的範圍；需求表達：說明需要；主動求助：向適合的人或資源尋求協助。
- 希望感、意義感與自我接納可用於使用者自己認同的經驗，不預設所有事件都要正向解讀。

## 避免的分類方式

不使用「人品好／不好」、高低智商、人格類型或疾病名稱。不要把健康狀態、收入、長期忍耐或不拒絕他人當成優點；健康習慣指當次可觀察的照顧行動，不指身體是否健康。休息與求助也不需要先完成成就才能記錄。

分類有重疊且不可能窮盡所有能力。專業技能可以自訂，例如程式設計、攝影或烘焙；不需要把每一種職業技能都塞進預設清單。新詞彙不自動取代或合併使用者原有標籤，避免歷史紀錄失真。

## 介面落實

先保留事件，再選填特質。分類瀏覽一次呈現一組選項；搜尋跨越全部分類；已選標籤獨立顯示、可直接移除。未被列入預設的歷史詞彙放在「自訂與既有標籤」。紀錄筆數只表示寫下的次數，不是優勢分數，也不要求每類選滿或達到均衡。
